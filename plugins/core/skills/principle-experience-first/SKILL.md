# Experience First

Choose user clarity, legibility, and polish over implementation convenience.

- **Real-surface quality:** Verify copy, spacing, contrast, and target language conventions (such as Hungarian accents and domain terminology) on the actual rendered surface.
- **Show, don't pad:** Fewer clear, accurate controls beat crowded dashboards or noisy placeholders.

## Guardrails

- Never trade away tenant isolation, authentication/authorization checks, or data honesty (never fabricate live indicators or zero costs) for visual convenience.
